## Introduction

A curated directory of Frontier AI Lab Companies headquarted in the United States of America. This directory is limited to metadata. Each piece of information was verified by a person-in-the-loop. Despite this verification of metadata, the information on record may need to be updated over time, and for more details please take a look at the Appendix's [List of Reasons for Stale URLs](#list-of-reasons-for-stale-urls). In addition, the directory is expected to grow over time based on the following dimensions:
1. The number of frontier labs covered
2. The number of languages supported
3. The type of metadata covered

Lastly, the owner of this repository is not affiliated with the Frontier AI Lab Companies.

## Appendix

### List of N/A Value Types

- **No account**: The company does not operate an official account on this platform.
- **No public pricing tier**: The company does not offer a self-service subscription plan or public token API pricing.
- **No public deprecation schedule**: The company does not publish a dedicated model deprecation log or schedule.
- **No public feed**: The company does not expose an official public RSS/Atom feed.
- **No public system status page**: The company does not maintain a dedicated public uptime or system status portal.
- **No dedicated research publications webpage**: The company does not publish a dedicated research publications landing page.
- **No dedicated safety portal**: The company does not publish a dedicated safety, responsibility, or transparency page.
- **No dedicated developer events page**: The company does not maintain a dedicated developer community events portal.

### List of Reasons for Stale URLs

A URL may become stale in this repository due to the following reasons:
1. The webpage URL address was changed
2. The account name was changed (and as a result, the webpage URL address was changed)
3. The webpage is no longer hosted
4. The website is no longer hosted
5. The account was deactivated
